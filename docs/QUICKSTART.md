# CCNest 使用说明

## 第一步：配置网络线路

- 一级是自己的上游线路。推荐连接已启动的 Clash / Mihomo 本地端口，也可导入节点或手动填写 HTTP / SOCKS5 代理；能直连二级时可不设一级。
- 二级使用自建 VPS 上的 HTTP / SOCKS5 代理，或服务商购买的静态家宽 / ISP 代理。VPS 出口通常是机房 IP，不等于住宅 IP。
- 点击“保存并逐级测试”，通过后核对并设置期望出口 IP；可点“查看出口 IP 质量”在 Scamalytics 查看 Fraud Score。

## 第二步：修改系统环境

建议勾选五项：区域格式、首选语言、时区、国家或地区、Windows 显示语言，选择与出口所在地一致的设置，点击“预览并立即应用”。

显示语言需已安装对应语言包，并注销后生效；重新登录后再继续。

## 第三步：检查环境

先在“概览”激活 Claude 环境，再到“环境检测”点击“开始检测”，自动包含专属浏览器检测。确认出口、语言、区域和时区一致；先处理“风险”和“待检测”，再开始使用。

## 第四步：使用专属浏览器

浏览器语言应与 Windows 和出口地区一致，保存后打开专属浏览器访问 Claude。修改语言后，关闭专属浏览器所有窗口再打开，并重新检测。登录资料会长期保留。

## 第五步：启动 Claude 应用

在“Claude 应用”中，通过 CCNest 启动 Claude Desktop，或打开 Claude Code 专属终端运行命令行。已运行的客户端或命令行会话，请先完全退出，再通过 CCNest 启动。

使用完毕，在“概览”结束环境并恢复设置。
